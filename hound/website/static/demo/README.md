## Demo script

1. Open `https://datadog.properrobotics.org/` in a private browser window so an older saved project does not appear.
2. Enter **Site address:** `Illustrative demo site, 1 Example Road, Singapore`. Set **Building name:** `Hound demo building`. Enter your own name for **Inspector**.
3. Under **Elevations**, leave **North** checked and untick East, South and West. Under **What makes up the building’s exterior?**, select only **Concrete or plastered walls**. The overview also shows glazing and metal, but this small walkthrough has no matching verified close-range evidence for those systems.
4. Select **Start inspection**. In **01 Building**, leave the floor plan empty. In **02 Visual inspection**, add `01-demo-north-overview-concrete-glass-metal.jpg` to North. Wait for analysis, read the observation, correct any unsupported claim, select the condition and façade integrity assessment, then mark it reviewed.
5. In **03 Close-range inspection**, use **Concrete or plastered walls → Add photo** and choose `02-close-rendered-wall-corner-crack.jpg`. Wait for analysis. Review the crack observation and any repair draft. Leave side, level and exact plan location unconfirmed unless you have evidence; check the condition, extent, structural concern and proposed action before marking reviewed.
6. The **Download Word report** button appears after the North visual photo and concrete/plastered-wall close photo are reviewed. `03-close-rendered-wall-edge-crack.jpg` is an optional second example; if added, review it too before downloading.

Leave coverage and previous-inspection findings blank for this illustrative run. Coverage needs measured façade and inspected areas; the number of photos cannot establish it. The exported document is a software demo draft, not a signed PFI assessment.
